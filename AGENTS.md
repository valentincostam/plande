# Plande

Academic degree planning for Argentine universities. SvelteKit 5 + TypeScript + TailwindCSS 4.

## Essentials

- **Package manager**: `bun` (not npm), `bunx` (not npx)
- **Typecheck**: `bun run check`
- **UI components**: DaisyUI
- **File naming**: kebab-case (`user-menu.svelte`)
