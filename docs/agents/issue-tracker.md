# Issue tracker

Issues for this repository live in Linear.

## Configuration

- Team: `Valentín`
- Integration: official Linear MCP server
- MCP server: `linear`
- Repository: `valentincostam/plande`

## Working with issues

Use the Linear MCP tools to search, read, create, and update issues. Do not use GitHub Issues or local Markdown files for this repository.

Before creating an issue, search Linear for an existing issue covering the same work. Create new issues in the `Valentín` team unless the user specifies another team.

Use the triage label mappings in `docs/agents/triage-labels.md`.
